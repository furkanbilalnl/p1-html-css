Waarom noem je de eerste HTML-pagina meestal "index.html"?

Een server opent automatisch index.html als de startpagina van een website. Je hoeft deze naam daarom niet zelf in de browser te typen.

Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

We gebruiken de HTML Living Standard van WHATWG. Het heet zo omdat de regels steeds worden vernieuwd en er geen HTML6 meer komt.

Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

CSS is nu verdeeld in kleine, losse onderdelen die apart worden bijgewerkt. Daarom is er geen één grote versie meer zoals CSS4.

Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?

Elke browser gebruikt een ander programma om de code te lezen. Daardoor ziet een pagina er soms een klein beetje anders uit.

Zoek op welke drie webbrowsers momenteel wereldwijd het meest worden gebruikt. Noem ze in volgorde van populariteit en vermeld de bron en datum van je gebruikte statistieken.

De top 3 is Google Chrome, Apple Safari en Microsoft Edge. Dit komt uit de cijfers van StatCounter (september 2026).
